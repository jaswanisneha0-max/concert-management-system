# 🎵 Concert Management System

## 📌 Project Description
Concert Management System is a web application developed using PHP, HTML, CSS and JavaScript that helps manage concerts, bookings and event details.

## 🛠 Technologies Used
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap

## ✨ Features
- User Registration and Login
- Concert Event Listing
- Ticket Booking
- Admin Panel
- Event Management

## 🚀 How to Run
1. Install XAMPP
2. Copy the project folder into `htdocs`
3. Start Apache and MySQL
4. Import `database.sql` in phpMyAdmin
5. Open in browser:

http://localhost/concert-management-system
